## Answer

### N01 — Nation selection (16 nations)

`mt_Nations/mn_<16 nations>` parent menu items + their corresponding
`PremierForm/Panel1/sb_<16 nations>` speed buttons, all with
`OnClick=ChangeNation`. The 16 nation rows for both surfaces are enumerated
in the **M01–M06 draft's panel/menu tables** (the `mt_Nations/mn_Rome` …
`mt_Nations/mn_Thracia` and `sb_Rome` … `sb_Thracia` rows reproduce all 16
verbatim from `form_controls.tsv`; same 16 names appear in
`state/sav.py` `NATIONS`).

Functions (function_list.tsv):

| Address | Function |
|---|---|
| `0x0045b660` | `TPremierForm_SelectNation` |
| `0x0045b6f0` | `TPremierForm_ChangeNation` |

`TPremierForm_SelectNation` is the read-side status probe (index 16 = all
nations, no status printed; per the inventory's row prose);
`TPremierForm_ChangeNation` is the menu's `OnClick` handler.

Live screenshot: `SS:FI_b1_11_menu_nations.png` (`MANIFEST-batch1.txt`,
hash `3d22bfc3b52330e08b710a91857af7fa29124dd1b42bf9db2d9aad437791941c`) —
the Nations menu open with Rome ticked. The other two screenshots for N03
(Carthage, Rome status panels) are cited under N03 below. Help topic 13
("Nations"): the menu opens with the dropdown of all 16 nations; the row
order matches `state/sav.py` `NATIONS`.

### N02 — All nations

`mt_Nations/mn_Allnations` (form_controls row
`PremierForm/MainMenu/mt_Nations/mn_Allnations`, caption=`All nations`,
OnClick=`ChangeNation`) and the corresponding
`PremierForm/Panel1/sb_Allnations` (already cited in the M01–M06 draft).
Functions:

| Address | Function |
|---|---|
| `0x0045b660` | `TPremierForm_SelectNation` (the read-side: prints no status for index 16) |
| `0x0045b6f0` | `TPremierForm_ChangeNation` (the menu side: sets viewed nation to 0x10) |
| `0x0043e210` | `TAreaMap_ShowCities` (area-map iteration: draws all when viewed nation is 0x10) |

The "index 16" pseudo-nation is the runtime sentinel for "all nations".
Reproduction in
[`2026-09-29-nation-view-origin-and-unit-map-clicks.md`](2026-09-29-nation-view-origin-and-unit-map-clicks.md)
(per inventory citation). Help topic 13: *"Selects 'all nations' (index 16)
… no nation status is printed."* `[derived]` carry-over — the sentinel is
code-only; no save diff exercises it.

### N03 — Nation status panel

`TInformation_ShowNationStatus @ 0x0043ba7c` (function_list.tsv; cited in
the inventory but the address isn't explicit in the row prose; recovered
from the function-table search).

The panel's render path reads from the nation record at the standard
offsets: name (`+0`), leader (`+0xB..+0x26`), capital (`+0x44A`),
cities_count (`+0x44C`), population (sum over records), unity (`+0x448`),
tax (`+0x44E`), money (treasury). Mobilization and treasury fields show
**only for the own nation** (per `state/sav.py`'s read; +0x44E is the
*conquered_by* — read separately per
[`decompiled-elimination-cleanup.md`](decompiled-elimination-cleanup.md)).

`MANIFEST-batch1.txt`):

## Three open notes

1. **N02's "index 16" sentinel is `[derived]`** (per inventory tag); no
   save diff exercises the "all nations" path because the harness has
   always selected one nation at a time in the 16 inventory runs.
   Carrying forward as a `[derived]`-flag carry-over; reproducing is one
   line of `pm = Game(); pm.select_nation("All nations")` in a live test,
   or read the field off a battle-sweep run's loaded 16-nation array.
2. **N03's "tribute and trade income" fields** listed in the help are
   *not* present in the captured Information-panel screenshots. Either
   the help is over-broad or the rendering hides these fields for the
   regular Nation status panel — `[derived]` carry-over. The Balance
   sheet dialog (row S04) does show them; reproduction is via that dialog.
3. **The 16 menu / 16 speed-button dual surface of N01** is partially
   redundant: a clone reproducing only the speed-button variant *or*
   only the menu variant still satisfies the inventory's row, but not
   both. Documented for the reproduction path; either surface alone is
   sufficient for the function-set (one `OnClick=ChangeNation` covers
   both surfaces).

## Inferences

- **N01's 16-nation dual surface (menu + speed button)** is one logical
  row that lives in two places. Both surfaces route to the same
  `ChangeNation` handler; reproducing either alone is enough functionally,
  both reproduces the original.
- **N02's "no status printed at index 16"** is a *rendering* guard, not
  a *data* removal: the all-nations selection is a real sentinel value
  the area-map iteration walks. A reproduction needs both: the area
  map's all-rows iteration, and the Information panel's index-16 guard
  that suppresses the status block.
