# Codex entry point

Read `CLAUDE.md` in full before working. It is the shared repository policy for Codex,
Claude Code and external agents; its filename does not limit its scope. Keep policy changes
there so both clients follow the same model-choice, worktree, review and monitoring rules.

Then read `docs/environment.md` for startup and tool availability. Read `docs/handover.md`
for research state, treating its dated paths, commit IDs and session details as historical
until checked against the current checkout.

For findings intake, read `.claude/skills/retrieve-findings/SKILL.md`. Codex also discovers
this same skill through `.agents/skills/retrieve-findings`; maintain the original rather
than a second copy.
